# Editable EasyEDA Pro project

`vl53l9cx-breakout-editable.epro2` is the native EasyEDA Pro project archive. It includes the schematic and linked PCB design as exported from the EasyEDA project.

To open it, download the archive and import it from the EasyEDA Pro start page, or use **File → Import → EasyEDA Professional** in the editor. Import creates a working project in your EasyEDA account; changes there do not update this GitHub copy automatically.

See the [EasyEDA Pro import guide](https://prodocs.easyeda.com/en/import-export/import-easyeda-pro/index.html).
